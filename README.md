# NO_Neuroslop — статья

Статический сайт — статья в ветке feature/neuroslop-article.

Как запустить локально:
1. Клонируйте репозиторий и переключитесь на ветку:
   git checkout feature/neuroslop-article
2. Откройте index.html в браузере или запустите минимальный сервер:
   python -m http.server 8000
   затем откройте http://localhost:8000

Поддерживает Light/Dark, адаптивность, прогресс чтения.
