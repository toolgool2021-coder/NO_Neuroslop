# NO NEUROSLOP

Авторский лонгрид-манифест Toolgool о нейрослопе и осмысленном использовании ИИ.

## Что нового
- Полный адаптивный editorial-редизайн: тёмная и светлая темы, типографика, CSS-графика без тяжёлых изображений.
- Содержание с поиском, подсветкой активной главы и счётчиком глав.
- Индикатор чтения, кнопка «Наверх», нативный Share и копирование цитаты.
- Исправлены битые символы, недостающая глава, canonical/OG и favicon.
- Семантика, доступность кнопок, reduced-motion и сохранение темы.

## Запуск

Откройте `index.html` или запустите `python -m http.server 8000`, затем перейдите на http://localhost:8000.

Статический сайт: без сборки, без backend и без зависимости от сторонних JS-библиотек.

Домен GitHub Pages: https://notslop.duckdns.org/
